## 1. 背景与已确认范围

小游戏难度、分类题文案及医生后台入口调整已提交为 `480a501`，生产后台已部署。患者 H5 因缺少可用素材地址沿用旧版，小程序 7.0.4 尚未上传。

9 月 2 日的包体优化已经将 23 项固定素材移出代码包，当前客户端拼接匿名 CDN 地址。用户明确要求保留现有七牛私有空间和 `https://cdn.whestsun.com`，采用签名访问，不新增域名。

2026-09-07 的只读探测结果：该域名 HTTPS 可连接；目标图片匿名访问返回 401，现有七牛签名访问返回 404；在当前配置的空间抽查图片和动作说明语音均未上传。这些结果支持继续使用现有签名机制，但不等同于素材上传后验收通过。

用户已确认：

- 后端批量返回固定素材签名清单，默认有效期 10 分钟。
- 保留 `8888` 未登录演示模式，只能获取通用素材清单中的文件签名。
- 素材签名由后端生成，小程序不持有长期签名密钥。
- 图片仍须全部预加载成功后才能开始对应游戏。
- 动作说明语音在播放前获取有效地址，失败保留文字说明。
- 37 段内置游戏音频保持原状；本项不制作或替换题目配音。
- 完成素材与接口验收后继续部署患者端，并上传微信开发版 7.0.4；上传、平台审核和正式上架分别报告实际状态。

## 2. 方案选择

| 方案 | 特点 | 决策 |
| --- | --- | --- |
| 每次返回该版本全部 23 项签名 | 一次请求满足游戏预取和动作说明，便于统一版本校验、过期更新及并发合并 | 采用 |
| 每个素材分别获取签名 | 请求更多，加载和重试状态更复杂 | 不采用 |

接口只生成 URL，不代理素材正文。图片、语音仍通过七牛 CDN 下载，业务服务器不承担媒体传输。

“私有”指七牛对象不能通过无签名地址直接读取。经用户确认，通用素材签名接口允许匿名演示访问，因此这 23 项通用素材不按患者身份保密；患者录像和骨架视频保持现有独立鉴权。

## 3. 固定清单与版本规则

当前素材版本为 `v-3aafe09211fd`，内容与已生成清单保持一致：

- 18 张图片：5 张图案、5 张分类、5 张声音配图、3 张拼图。
- 5 段动作说明：高抬腿、坐站、划船、后踢、肩部推举。
- 对象前缀固定为 `motioncare/static-assets/`。
- 对象名称使用 `<asset_version>/<业务 key>.<SHA-256 前 12 位>.<扩展名>`。

扩展现有素材生成脚本，将同一份生成结果写入后端代码内的版本化 JSON 清单，例如 `backend/apps/common/miniapp_static_asset_manifests/v-3aafe09211fd.json`。后端镜像随代码包含该清单，不依赖小程序构建输出目录或运行时从 CDN 下载清单。

生成与 `--check` 同时检查前端路径表、后端清单及外部素材产物的一致性。保留已发布版本的清单和对象；新版本添加新的版本文件，不覆盖旧文件。后端仅从显式登记、通过规范校验的版本清单取对象 Key，不将请求参数直接拼成文件系统路径或七牛对象路径。

每份清单必须恰好包含 23 个规范业务 key，校验类型、扩展名、字节数、完整 SHA-256、文件名哈希和版本前缀，不允许患者视频或其他路径混入。运行时不查询患者、处方或训练记录表，不新增数据库模型和 migration。

## 4. 签名清单接口

### 4.1 请求与访问范围

`GET /api/patient-app/static-assets/?version=v-3aafe09211fd`

- 允许匿名访问；使用独立的 `AllowAny` 素材视图，不继承患者业务视图。
- 必须且只能传一个 `version`。缺失、重复参数及额外的 `key`、`path`、`url` 等参数返回 400。
- 格式合法但未登记的版本返回 404；非 GET 方法返回 405。
- 无论有无患者登录态，接口只能返回选中清单的 23 个固定对象；不接受患者 ID、对象 Key 或外部 URL。
- 客户端使用现有 `publicRequest`，不发送患者 token，也不因素材失败清除真实登录态。

### 4.2 成功响应

返回对象包含以下字段，时间使用 Unix 秒：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `asset_version` | string | 与请求、编译清单一致的素材版本 |
| `issued_at` | integer | 本次签名生成时间 |
| `expires_at` | integer | 所有 URL 的统一到期时间 |
| `assets` | array | 恰好 23 项素材 |
| `assets[].key` | string | 规范业务 key |
| `assets[].relative_path` | string | 版本化相对路径 |
| `assets[].url` | string | 使用现有域名的 HTTPS 七牛签名地址 |
| `assets[].content_type` | string | 图片为 `image/webp`，动作说明语音为 `audio/mp4` |
| `assets[].size_bytes` | integer | 文件字节数 |
| `assets[].sha256` | string | 完整内容 SHA-256 |

不返回长期密钥、上传凭据、患者信息或任意可签名路径。URL 中包含正常七牛下载签名参数；不把签名 URL 写进应用日志、埋点或错误文案。

### 4.3 签名与配置

- 使用现有七牛私有下载签名函数，逐个签发后端清单中的精确对象地址。
- 新增独立的 `MINIAPP_STATIC_ASSET_BASE_URL`，正式值为 `https://cdn.whestsun.com/motioncare/static-assets`；不修改训练视频使用的 `QINIU_DOWNLOAD_DOMAIN`。
- 新增 `MINIAPP_STATIC_ASSET_URL_TTL_SECONDS`，默认 600 秒，限定为 120–3600 秒；无效配置拒绝启动。
- 基础地址要求绝对 HTTPS、无账号密码、query 或 fragment，固定使用上述素材前缀；私有存储空间沿用已有七牛配置。
- 客户端保留 `TARO_APP_ASSET_BASE_URL`，同样配置上述地址，但它仅用于验证返回 URL 的来源与路径边界，不再自行生成匿名下载地址。
- 清单响应设置 `Cache-Control: no-store`，不使用公共 HTTP 缓存或服务端签名响应缓存。每次有效请求返回完整、同时签发的清单；如其中一项签发失败，返回整体 503。

### 4.4 限流与失败行为

复用 `RedisFixedWindowRateThrottle` 的原子计数能力，增加独立命名空间与配置，默认每个可信客户端 IP 每 60 秒最多 60 次请求。沿用现有可信代理 IP 规则，不读取任意用户伪造的转发链。

超过配额返回 429；Redis 或签名配置不可用返回脱敏的 503。错误文案统一说明素材暂不可用，不返回 SDK 原始异常、签名 URL 或密钥。限流命中时不执行签名，不修改业务数据。

## 5. 客户端清单与过期处理

新增独立签名清单客户端模块，供游戏图片与动作说明共同使用：

1. 以编译期素材版本请求完整清单，同一版本的并发调用合并为一个请求。
2. 验证版本、23 项规范 key 的完整性与唯一性，以及每项路径、媒体类型、字节数、SHA-256 和编译清单一致。
3. 验证 URL 为 HTTPS，来源与基础路径符合 `TARO_APP_ASSET_BASE_URL`，路径恰好对应本项文件；允许且检查七牛 `e` 与 `token` 参数，`e` 必须与响应到期时间一致，拒绝重复签名参数、账号密码、fragment 或路径逃逸。
4. 清单只缓存在进程内存中，不写 Storage，不建立图片或语音的持久化文件缓存。
5. 使用 `expires_at - issued_at` 计算剩余使用窗口，从请求发起时间扣除网络耗时，并预留 60 秒安全余量，避免依赖手机与服务器的绝对时钟一致。检测到客户端时钟回拨或窗口耗尽即丢弃缓存。
6. 获取失败不缓存失败 Promise；较早请求的迟到结果不得覆盖较新的强制刷新结果。
7. 每次图片预取或语音播放尝试最多强制刷新一次签名并重试一次；刷新失败或第二次失败交由现有页面失败状态处理，不循环请求。限流、明确的版本不支持或取消操作不自动重试。

固定相对路径校验与签名 URL 校验分开：原相对路径仍禁止 query，只有来自受控接口的完整签名 URL允许指定 query 参数，不能为支持签名而放宽任意路径规则。

## 6. 游戏图片与动作说明语音

### 6.1 游戏图片

先获取清单，再以当前游戏所需 key 获取签名 URL，继续使用现有预取并发数 3、进度、临时路径和全部素材就绪门禁。颜色顺序与反应抑制等不需要图片的游戏不为此请求清单。

预取成功后的本轮游戏使用 `Taro.getImageInfo` 返回的临时路径。签名到期不会主动清空已经就绪的本轮图片，也不触发下载、计时重置或重新出题。下载失败可执行一次有界刷新；仍失败则显示重试和返回按钮，不能开始计时或生成训练结果。

保留现有请求代次与 `isCurrent` 检查；页面隐藏、卸载、切换动作或取消后，迟到的签名与下载结果不能标记新页面就绪、更新旧页面状态或启动训练。共享签名请求不因一个页面退出而破坏另一个消费者。

### 6.2 动作说明语音

把“是否有此动作语音”与“异步取得播放 URL”分离，不再在模块导入时生成固定远端地址。页面仍按已存在的动作 key 决定按钮是否显示。

自动播放和手动重播都先取得有效签名，再调用原播放器。签名请求开始前记录本次播放代次；签名返回和播放结束后都检查页面可见性、当前动作和代次，防止离页后突然发声。

保留每次访问自动播放一次、重播按钮、前后台停止和销毁。一次播放尝试包含签名请求、可能的一次刷新和媒体播放，总超时仍为 90 秒；取消或超时不能额外启动自动重试。失败显示“语音播放失败，请阅读文字说明”，不阻止动作预览或正式训练。

## 7. 素材发布与配置

复用现有 23 项素材生成、SHA-256 校验和七牛幂等上传命令。继续使用 `insertOnly`，已存在且元数据一致则跳过，不覆盖、不删除历史对象；不调整整个空间的私有权限。

新增签名访问验收模式，保留原公开验收脚本作为旧方案工具。签名验收从正式接口获取 URL，并逐项检查状态 200、媒体类型、字节数及 SHA-256；不再要求私有响应具备 `public, max-age=31536000, immutable`。业务 key 与哈希路径的不可变约束仍然成立。

验收日志只记录业务 key、状态及校验结果，不能输出完整签名 URL。抽查同一真实对象：无签名或篡改签名拒绝访问；有效签名可下载；使用已经过期的正确签名也拒绝访问。检查 CDN 不因缓存而绕过签名有效期。

部署时保证后端 `MINIAPP_STATIC_ASSET_BASE_URL`、客户端 `TARO_APP_ASSET_BASE_URL` 和七牛对象前缀一致；通过现有服务环境配置与构建变量注入，不把本地开发地址打入正式包。微信正式 API 地址沿用 `https://mcare-wx.whestsun.com/api`。

`cdn.whestsun.com` 仍需配置为微信 `downloadFile` 合法域名；签名不会取消 HTTPS 或合法域名要求。域名配置是否已完成必须依据微信平台状态或真机验证，不能以 CLI 上传成功代替。

## 8. 发布顺序与兼容

1. 生成并校验固定版本的全部 23 个素材，上传到现有私有空间，确认目录不受清理策略误删。
2. 将支持当前版本清单的后端接口及配置先部署，并用有效、失效与匿名请求完成真实素材验收。
3. 后端验收成功后，再设置正式客户端构建变量并发布患者 H5、构建和上传微信开发版 7.0.4。已有流水线由素材变量决定是否构建新 H5，因此先保持该变量未启用，避免客户端先于签名接口上线。
4. 验证游戏预取、动作说明、真实患者和 `8888` 演示路径；分别记录后台部署、H5 更新、CLI 上传、真机验收、平台审核或正式上架状态。

后端保留所有仍在使用的版本清单。客户端回滚仅切回已验证且匹配的包；已采用签名访问的客户端仍存在时，不能回滚到不提供签名接口的后端。现存依赖匿名 URL 的旧包不自动获得签名能力，保留原运行版本直至新客户端验收完成。

## 9. 验收标准

### 后端

- 匿名及已登录调用均只返回固定 23 项；无患者信息，签名准确到对象路径且默认期限 600 秒。
- 缺失、重复、额外参数及未知版本分别返回约定错误；路径穿越、患者对象 Key、任意 URL 不能换取签名。
- 错误、日志和限流不会泄露凭据；第 61 次请求被限流，Redis 失败返回 503。
- 前后端生成清单一致，后端镜像包含版本清单，已有清单不被覆盖。
- 原患者业务接口、训练视频与骨架视频鉴权回归通过。

### 小程序与 H5

- 并发合并、临近到期更新、请求耗时与时钟回拨、失败缓存清理和迟到响应隔离均有行为测试。
- 非法清单、非 HTTPS、错误来源/路径、过期及重复签名参数被拒绝。
- 四款图片游戏可完成预加载；全部成功前不能开始，失败刷新有界，临时图片不因签名过期而清空。
- 离页或切动作后迟到结果无副作用；自动播放、重播和总计 90 秒超时符合现有体验。
- `8888` 可以加载全部通用素材，不读取真实 token、处方、历史或待上传数据，不上传演示训练结果。
- 六款游戏难度、两秒展示、分类文案及医生端难度入口等 `480a501` 行为保持通过。
- 前后端测试、代码规范、管理端与患者 H5 构建、微信开发和生产构建及包体预算检查通过；独立小程序 TypeScript 的既有问题单独记录，不冒充通过。

### 外部发布

- 23 项素材签名 URL 均通过正文完整性与媒体类型检查，匿名、失效或篡改签名不能绕过私有访问。
- 微信合法域名与真机验证有明确结果；上传版本号为 7.0.4，保留 CLI 成功证据。
- 签名 API 无法提供、CDN 无法验证、域名或微信平台步骤未完成时，如实标明具体未完成阶段。
