# 训练录像诊断日志

## 行为

捕获 recording、compression、file_read、session、status、upload、finalize 七个阶段失败。记录事件 UUID、发生时间、客户端训练会话 UUID、可选 video_id、可选分片序号、稳定错误码、脱敏错误摘要、HTTP 状态、网络类型、系统平台、微信 SDK 和小程序版本。严禁保存视频、姓名、手机号、令牌、签名 URL、文件路径或响应体。

小程序先同步保存事件到最多 100 条的独立待发队列，再尽力发送；上传日志不得阻塞训练、覆盖原错误或递归生成日志。记录保留 15 天，过期即删除。每次失败、回到前台、网络恢复时单通道补报，后台停止重试，网络异常采用退避且不忙循环。日志以独立事件 UUID 去重。收到服务端确认后才移除，重复发送不产生重复行。演示模式不记录、不上报。待发队列与当前登录作用域绑定，退出和身份更换后不把旧日志归属到新账号；不在日志存储内复制令牌。无有效身份时不得公开匿名写入。

## 服务端契约

POST `/api/patient-app/training-upload-diagnostics/`，使用现有患者端 Bearer 认证，单次接收一个事件：

```json
{"event_id":"UUID","occurred_at":"ISO8601","client_session_id":"UUID","stage":"upload","error_code":"upload_network_failed","message":"uploadFile:fail timeout","video_id":1,"segment_index":0,"http_status":500,"network_type":"wifi","platform":"ios","sdk_version":"3.0.0","app_version":"1.0.0"}
```

video_id、segment_index、http_status、client_session_id 可缺省，其余字符串有长度上限。网络/平台仅接受有限值或有限长度字段，异常摘要在客户端和服务端二次脱敏，未知字段拒绝。身份从服务端认证推导；若携带 video_id，必须属于当前患者项目关系，且 client_session_id 如提供则匹配。事件 UUID 与患者项目关系联合唯一，跨账号不能共享确认。返回 200 `{"event_id":"UUID"}`（含重复事件）。客户端格式错误不可无限重试；401/403 暂停，不跳转、不清除其他业务状态；429/5xx/网络失败保留重试。接口限流，JSON 请求体和摘要限长。

存入独立数据库模型，接收时间起最多十五天可查询。每小时 Celery 清理超过十五天的记录；查询命令同样排除已过期记录，接收旧事件不重新延长已有记录的期限。提供按 video_id/client_session_id 筛选的服务端管理命令，不新增管理页面。运维命令输出仅包含脱敏字段。保留训练视频和业务记录不受日志清理影响。
