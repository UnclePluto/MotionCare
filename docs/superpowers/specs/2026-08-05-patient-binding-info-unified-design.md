# 患者绑定信息统一设计

## 1. 目标

患者详情中的“小程序临时绑定码”和“穿戴设备”当前分成上下两个区域，设备简码输入框直接
占据页面，操作入口与患者临时绑定码不一致。此次调整把两类绑定统一为一个“患者绑定信息”
区域，让医生从同一处查看状态并完成操作。

本次只调整医生端前端的信息结构和交互，不改变后端接口、患者与设备归属、解绑语义、
通信测试、响铃能力或并发隔离规则。

## 2. 页面结构

外层“患者接入”标题保持不变。原“小程序临时绑定码”标题改为“患者绑定信息”。

“患者绑定信息”标题右侧使用同一个操作区：

- 始终保留“生成临时绑定码”。
- 患者未绑定穿戴设备时显示“绑定穿戴设备”。
- 患者已绑定穿戴设备时隐藏“绑定穿戴设备”，改为显示“通信测试”“让设备响铃”
  （仅设备能力支持时）和“解绑设备”。
- 原“撤销绑定”继续用于撤销小程序患者绑定，与穿戴设备解绑保持两个独立动作。

页面下方不再显示独立的“穿戴设备”标题、分隔线和行内简码输入框。

## 3. 患者绑定信息表格

沿用现有 `Descriptions` 表格，并在原有小程序绑定字段中增加：

- 设备简码：展示后端绑定对象的 `short_code`。
- 设备 ID：展示后端绑定对象的 `device_id`。

未绑定设备、设备状态加载中或没有可展示值时使用“—”，不展示旧的“当前设备”独立表格。
设备绑定时间继续展示为“设备绑定时间”，避免与小程序“最近绑定时间”混淆。

表格最终包含：

- 患者绑定状态
- 有效绑定码
- 最近绑定时间
- 绑定码过期时间
- 登录过期时间
- 设备简码
- 设备 ID
- 设备绑定时间

## 4. 穿戴设备绑定弹窗

点击“绑定穿戴设备”打开 Ant Design `Modal`：

- 标题为“绑定穿戴设备”。
- 输入框标签和无障碍名称为“设备固定简码”。
- 只接受数字，最多四位。
- 只有输入完整四位数字后，“确认绑定”按钮才可用。
- 回车与点击“确认绑定”执行相同行为。
- 提交期间按钮显示加载态，避免重复提交。
- 绑定失败时在弹窗内直接展示后端返回的安全错误信息。
- 取消或关闭弹窗时清空本次输入和错误状态。

绑定成功后关闭弹窗、清空简码、立即更新当前患者的查询缓存和表格，并沿用现有逻辑自动
执行一次设备通信测试。

## 5. 已绑定设备操作

通信测试、响铃和解绑沿用现有接口和异步保护：

- 通信测试只更新请求所属的当前患者和当前设备。
- 仅通信测试明确返回 `ring` 能力时显示“让设备响铃”。
- 解绑继续使用二次确认弹窗，并明确“历史研究数据不会删除”。
- 解绑成功后立即清空设备表格字段，右上角重新显示“绑定穿戴设备”。
- 切换患者时关闭设备绑定/解绑弹窗、清空简码和成功提示，忽略上一患者迟到的绑定或通信响应。

小程序临时绑定码的生成、只显示一次、过期时间和撤销行为保持不变。

## 6. 组件边界

`ProjectPatientBindingCard` 负责统一布局和小程序绑定状态。

穿戴设备查询、绑定、通信测试、响铃、解绑和迟到响应隔离继续集中在穿戴设备模块中；
实现时将现有 `WearableBindingPanel` 拆成可被统一卡片消费的控制器与展示片段，避免在
`ProjectPatientBindingCard` 中复制设备领域逻辑。该组件目前只被患者绑定卡片使用，因此
允许在保持导出兼容的前提下调整其接口。

## 7. 错误与加载状态

- 小程序绑定状态和设备绑定状态分别加载，任一失败不遮蔽另一类信息。
- 设备状态加载期间表格设备字段显示“—”，绑定按钮不可用或不显示。
- 设备绑定失败保留弹窗和输入值，方便医生修正后重试。
- 通信测试、响铃和解绑错误继续展示在患者绑定信息区域下方。
- 所有错误信息优先展示后端 `detail`，没有安全详情时使用现有中文兜底文案。

## 8. 测试与验收

前端测试覆盖：

- 标题显示为“患者绑定信息”，不再显示“小程序临时绑定码”和独立“穿戴设备”区域。
- “生成临时绑定码”和“绑定穿戴设备”位于同一操作区。
- 点击设备绑定按钮打开弹窗，三位简码不能提交，四位简码可以提交。
- 绑定成功后表格展示设备简码和设备 ID，弹窗关闭并触发通信测试。
- 已绑定设备时不显示绑定按钮，保留通信测试、能力受控响铃和解绑。
- 解绑后表格设备字段清空并恢复绑定按钮。
- 切换患者时清除弹窗状态，并阻止迟到响应污染当前患者。
- 小程序绑定码生成、撤销和只显示一次的既有测试继续通过。

完成前运行：

```bash
cd frontend
npm run test
npm run lint
npm run build
```

## 9. 非目标

- 不新增或修改后端 API、模型与迁移。
- 不允许替换已绑定设备；必须先解绑再重新绑定。
- 不调整小程序患者端页面。
- 不升级 Ant Design、React、TanStack Query 或其它依赖。
