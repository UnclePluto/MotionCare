# 穿戴健康面板平铺改版设计

> 状态：implemented（2026-08-03 血氧轴与日汇总精简调整已验收）
> 日期：2026-08-03
> 范围：简化患者“穿戴健康”页的筛选、趋势图、Tooltip 与日汇总展示
> 关联：`docs/superpowers/specs/2026-07-23-wearable-openapi-integration-design.md`

## 1. 目标与边界

本次只调整患者“训练与健康 > 穿戴健康”页的前端展示与交互，不修改穿戴设备模型、同步规则、数据归属、后端查询接口或设备台账。

目标：

1. 移除当前页的“设备配置”模块，降低研究人员查看数据时的干扰。
2. 同时展示心率、血压、血氧和步数趋势，取消指标与分桶下拉筛选。
3. 提供近 7 天、近 30 天和自定义日期范围。
4. 统一日汇总表，补充步数并移除同步状态信息。
5. 将图表 Tooltip 的通用 `value` 改为业务指标名称。

## 2. 页面结构

页面从上到下调整为：

1. 设备摘要：保留绑定设备、型号、通信状态、电量、最近通信和最近健康同步。
2. 查询与操作栏：
   - 日期快捷选项：“近 7 天”“近 30 天”“自定义”。
   - 默认选择“近 30 天”。
   - 仅选择“自定义”时显示日期范围选择器。
   - 自定义范围最长 31 个自然日，与原始测量查询接口保持一致。
   - 保留“通信测试”。
   - “主动同步”不再依赖当前指标，一次为心率、血压、血氧和步数全部排队。
3. 健康趋势：四张独立卡片同时展示。
4. 日汇总：单一统一表格展示全部指标。

“设备配置”标题、说明、采集间隔输入、步数开关及对应下发按钮全部从当前页面移除。后端配置接口保留，不在本次范围内删除。

## 3. 健康趋势

趋势区使用响应式网格：

- 桌面端两列。
- 窄屏单列。
- 四张卡片依次为心率、血压、血氧、步数。

数据读取：

- 心率、血压、血氧按同一日期范围并行请求原始测量接口，固定使用 `bucket=raw` 和单页上限 500。
- 步数复用日汇总接口。
- 每张卡片独立展示加载、失败和无数据状态，一项失败不阻塞其他三项。

设备操作：

- 心率、血压、血氧卡片各自承载对应的“主动测量”操作，并继续遵循设备能力与请求状态限制。
- 顶部“主动同步”调用现有全指标同步语义，不提交 `metric_type`。

Tooltip 文案：

- 心率：`心率`
- 血氧：`血氧`
- 步数：`步数`
- 血压：`收缩压`、`舒张压`

图表内部仍可使用 `value` 作为数值字段；通过图表配置声明展示名称，避免 Tooltip 暴露实现字段名。

## 4. 时间筛选

快捷范围都以 `Asia/Shanghai` 当日为结束日期：

- 近 7 天：今天及之前 6 天。
- 近 30 天：今天及之前 29 天。
- 自定义：用户选择开始和结束日期，最多 31 个自然日。

切换快捷范围后立即更新四张趋势图和日汇总。切换患者或项目患者时，查询键必须包含患者、项目患者和日期范围，避免缓存串用。

## 5. 日汇总

日汇总不再依赖当前选中指标，使用统一列：

- 日期
- 心率均值
- 收缩压均值、舒张压均值
- 血氧均值
- 步数

移除：

- 最低值、最高值和测量次数列。
- 心率、血压、血氧、步数的同步状态列。
- 步数归属状态列。

无值继续显示 `—`。

## 6. 状态与错误处理

- 四项趋势请求独立处理加载、错误和空态。
- 日汇总保留独立加载、错误和空态。
- 主动测量后的轮询只刷新对应指标及日汇总。
- 全指标主动同步后刷新同步摘要、四项趋势和日汇总，但不提前宣称新数据已经到达。
- 页面切换患者、项目或时间范围后，旧操作反馈不得串到新范围。

## 7. 测试与验收

前端测试至少覆盖：

1. 页面不再渲染设备配置相关控件。
2. 默认近 30 天，并可切换近 7 天和自定义范围。
3. 四项趋势同时请求和渲染，固定使用原始测量数据。
4. 单项趋势失败不影响其他趋势。
5. Tooltip 使用业务指标名称，不显示 `value`。
6. 主动同步不提交单一指标，主动测量作用于对应卡片。
7. 日汇总只包含日期、四项均值和步数，不包含极值、次数、同步状态及归属状态列。
8. 现有通信测试、异步操作隔离和患者切换行为不回归。

完成前运行：

```bash
cd frontend
npm run test
npm run lint
npm run build
```

## 8. 血氧纵轴与日汇总精简调整

### 8.1 血氧纵轴

血氧趋势继续按当前有效数据动态计算纵轴，但正常血氧数据不得导致纵轴紧贴
`95%–100%`：

- 纵轴上限固定不超过 `100%`。
- 正常数据的最低展示下限为 `85%`，因此 `95%–99%` 应显示为
  `85%–100%`。
- 若实际数据低于 `85%`，纵轴下限继续根据实际最小值和动态余量向下扩展，
  不得裁剪异常低值。
- 动态余量取“至少 2 个百分点”和“当前数据跨度的 50%”中的较大值。
- 没有有效血氧数据时不强制设置纵轴范围。

### 8.2 日汇总列

日汇总表精简为以下 6 列：

1. 日期
2. 心率均值
3. 收缩压均值
4. 舒张压均值
5. 血氧均值
6. 步数

最低值、最高值、测量次数、同步状态和归属状态不再展示。接口仍可保留这些
字段，避免影响已有数据同步与其他调用方；本次只收窄患者穿戴健康页的表格列。

### 8.3 验收

- 血氧数据 `95%–99%` 时，纵轴范围为 `85%–100%`。
- 血氧出现低于 `85%` 的数据时，纵轴下限必须覆盖该数据并保留动态余量。
- 日汇总表只展示上述 6 列。
- 顶部日期筛选继续同时驱动趋势图和日汇总表。
