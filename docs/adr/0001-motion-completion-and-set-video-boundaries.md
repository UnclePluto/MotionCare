# 按次计完成，按组保存视频与异步分析

四个计数组动作的一次运动包含多个组，每组拥有独立录像与分析结果，但每周完成次数以整次运动为单位。全部规定组做完且视频全部上传成功后才计一次；上传中的组可以与下一组运动并行，分析结果异步产生，不阻塞客户端完成确认。

现有管线中每个成功视频对应一条训练记录，直接沿用记录条数统计会把三组算成三次。因此必须在业务上区分“一次运动”“组”和“录像尝试”：重做只替换未完成组的录制尝试，上传重试或分析回调不能增加完成次数。这保留了逐组审阅与后台分析能力，同时避免网络速度和算法耗时控制用户的运动节奏。
